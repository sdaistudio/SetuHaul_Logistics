SetuHaul Logistics — driver exception service

When many drivers report delays at once, SetuHaul answers each one in English, Hindi or Hinglish with a dock slot the truck can really make, and never promises the same capacity twice. Language at the edges; a deterministic solver decides every slot; a person decides when no safe answer exists.

Built on the 4 August 2026 Jaipur snapshot for the FDE Academy challenge. Everything below is generated from the code in the repository.
