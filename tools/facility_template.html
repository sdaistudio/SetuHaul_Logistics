Facility day: from coordinator tool to agents

One facility (Jaipur DC, six docks: standard, heavy, reefer), one day. First the coordinator gets more power with a scheduling algorithm (Stage 1). Then the same process is run by agents, with guardrails and a person at every decision that is not safe to automate (Stage 2). Every number below comes from running the code on the supplied data.
